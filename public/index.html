Contrat JSON et règles du TP
Champs obligatoires : incident_id, category, risk, source_ip, summary, evidence, action. Le résumé est libre (15–600 caractères). Les preuves sont 2 à 4 extraits exacts distincts des logs, d’au moins 12 caractères.
Catégories : normal | brute_force | sql_injection | prompt_injection. Risques : low | medium | high | critical. « normal » signifie qu’aucune attaque n’est identifiée ; une panne peut donc être normal / medium.
Règles dans cet ordre : injection de prompt ou risque critique → escalate ; risque élevé avec IP → block_ip ; risque élevé sans IP → escalate ; sinon → observe. Ces règles sont simplifiées pour le TP.
